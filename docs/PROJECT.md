# 项目介绍与面试讲解素材

## 一句话介绍

知序是用于企业内部知识沉淀与问答的通用平台，将文件导入、解析验收、索引构建、在线问答和运行监测串成可检查的流程。

## 用户和问题

员工需要从制度、产品与流程文档里找答案；知识维护人员需要知道文件是否解析正确、是否索引成功；管理员需要组合模型服务并排查耗时、用量和失败。通用聊天窗口无法解决知识版本、处理状态和来源追溯的问题。

## 主要产品决策

- 先覆盖文件→知识→答案的主流程，暂不引入复杂 Agent 画布。
- 先让用户检查分块，再构建索引，降低“上传成功但知识不可用”的误解。
- LLM、Embedding、Rerank 分开配置，避免把三种能力误当成可互换的模型名称。
- 回答附带文档版本与片段快照，方便核查，而不是只显示一个没有出处的答案。
- 新索引失败时保留旧版本；停用后立即在 SQL 过滤，优先保证资料有效性。
- 试用阶段允许任意切换角色，减少登录成本；明确它不构成真实企业权限控制。

## 可以展示的工程证据

真实文件解析后的分块与来源、任务状态和失败原因、Qdrant 混合召回、LangChain 流式调用、引用快照、匿名会话隔离、用量缺失处理，以及自动化测试和数据库迁移。演示时使用 examples/ 内的虚构资料。

## 如何讲结果

当前结果是功能闭环与测试证据，不应声称已服务真实企业、提升某个百分比或达到未压测容量。需要补充真实用户验证和独立问题集，才能报告业务收益和质量指标。

下一步可评测 Recall@K、引用有效率、可依据回答比例、资料外问题拒答表现、首字时间和每问成本。调参样本与最终验收样本分开；同时记录文件总页数、分块量、所选模型和并发条件。
